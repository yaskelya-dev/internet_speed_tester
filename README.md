# Internet Speed Tester
Скрипт на Python для измерения средней скорости загрузки файла по HTTP/HTTPS.

## Требования
- Python 3.8+

## Установка
1. Клонируйте репозиторий:

```bash
git clone https://github.com/yaskelya-dev/internet_speed_tester.git
cd ./internet_speed_tester/

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python3 ./internet_speed_tester.py
```

Повторные запуски уже просто:
```bash
python3 ./internet_speed_tester.py
```
